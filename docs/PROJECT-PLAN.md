# Oru Hello — project baseline

## Locked requirements
- React-based website (Vite + TypeScript)
- Responsive across phone, tablet, laptop and desktop
- User supplies UI/UX requirements page by page
- Separate frontend and backend workspaces; backend stays optional
- Interactive song-story concept; final page designs and functionality will be defined later

## Not decided yet
- Final page count, routes and navigation
- Whether backend/database is necessary
- Exact chosen song file, lyrics timestamps, and hosting
- Visual system, copy, accessibility behaviors, share/response workflow

Do not assume these decisions until specified.

## Page 01 — Envelope invitation (implemented)
- Full-viewport responsive ivory / champagne / gold introduction inspired by supplied reference.
- Accessible tappable envelope with CSS wax seal, opening flap and letter rise.
- Transition into elegant white stationery view with animated handwritten placeholder copy.
- Replay affordance, reduced-motion support, tablet/desktop/mobile layout.
- Arabic invocation displayed as in visual reference; wording should be confirmed before release.
- This page does not start music or navigate to another page; waiting for next page instructions.
- Handwriting animation is a line-by-line reveal (not real pen-path stroke tracing). Live Google Font needs network.
